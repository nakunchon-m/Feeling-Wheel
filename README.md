# 💜 ช่วงนี้คุณคิดอย่างไรกับฉัน? — Anonymous Mood Wheel

เว็บแอป Streamlit ให้เพื่อน ๆ "แปะสติกเกอร์ความรู้สึก" ถึงใครสักคนบนวงล้อ แบบ **ไม่ระบุตัวตนจริง ๆ**
ใครก็สร้างบอร์ดของตัวเองได้ (เป็นคนถูกประเมินได้) และแต่ละคนโหวตได้ **1 ครั้งต่อรอบ** (สัปดาห์ / เดือน / 3 เดือน) โดยบอร์ดไม่มีวันหมดอายุ

| หน้า | ทำอะไร |
|---|---|
| หน้าแรก | สร้างบอร์ด · เปิดลิงก์ที่ได้รับ · เข้าดูผลบอร์ดของฉัน |
| หน้าโหวต `?b=…&c=…` | เลือกได้ 1–3 ความรู้สึก (21 แบบ ใน 3 กลุ่ม ดีนะ / เฉย ๆ / ไม่ดี) + ระดับ นิดหน่อย / ค่อนข้าง / มาก ๆ (เช่น "โกรธมาก ๆ", "สดชื่นมาก ๆ") พร้อมวงล้อพรีวิว |
| แดชบอร์ดเจ้าของ | วงล้อสติกเกอร์ 3D (ขนาดจุด = ความรู้สึกมาก/น้อย), ดัชนีความรู้สึก −100…+100, สัดส่วน, เทรนด์ย้อนหลัง, จัดการโค้ด, ตั้งค่า, ลบบอร์ด |

---

## 🔒 ไม่ระบุตัวตนอย่างไร (Privacy by design)

**สิ่งที่ระบบ *ไม่* เก็บเลย:** ชื่อ, อีเมล, การล็อกอิน, IP, user agent, เวลาที่โหวต, ข้อความอิสระ

**สิ่งที่เก็บ** (ดู `moodwheel/store.py`)

| ตาราง | เก็บอะไร |
|---|---|
| `mw_boards` | ชื่อที่แสดง, การตั้งค่า, **SHA-256** ของกุญแจเจ้าของ |
| `mw_codes` | **SHA-256** ของโค้ดเชิญ (ตัวโค้ดจริงไม่ถูกเก็บ จึงแสดงซ้ำไม่ได้) |
| `mw_redemptions` | (บอร์ด, รอบ, hash ของโค้ด) — รู้แค่ว่า "โค้ดนี้ใช้ไปแล้วในรอบนี้" เพื่อกันโหวตซ้ำ |
| `mw_tallies` | **ตัวนับ** (บอร์ด, รอบ, ความรู้สึก, ระดับ) → จำนวน — ไม่มีแถวรายคน |
| `mw_ballots` | ตัวนับจำนวนผู้โหวตต่อรอบ |

- ไม่มีคอลัมน์ไหนเชื่อม "โค้ด" กับ "ความรู้สึก" — คำตอบถูก **บวกเข้าตัวนับทันที**
- เจ้าของบอร์ด **ไม่เห็นว่าโค้ดไหนโหวตแล้ว** และไม่เห็นจำนวนผู้โหวตจนกว่าจะถึง **เกณฑ์ขั้นต่ำ (≥ 3 คน, ปรับได้ 3–20)**
- ค่าเริ่มต้น **"เปิดผลเมื่อจบรอบ"** — ระหว่างรอบไม่บอกอะไรเลย เพื่อกันการเดาจากจังหวะเวลา (เลือกโหมด "ดูได้ทันทีเมื่อถึงเกณฑ์" ได้)
- รอบที่คนโหวตไม่ถึงเกณฑ์ จะ **ไม่เปิดผลตลอดไป**
- ตำแหน่งสติกเกอร์บนวงล้อเป็นการสุ่ม ไม่บอกลำดับก่อน-หลัง
- ปิด usage stats ของ Streamlit ใน `.streamlit/config.toml`

**ข้อจำกัดที่ควรรู้ (พูดตรง ๆ)**
1. ถ้ามีคนโหวตน้อยมาก หรือเจ้าของถามเพื่อนทีละคนว่า "โหวตยัง" แล้วคอยดูผลในโหมด live ก็อาจเดาได้ → ใช้โหมด "เปิดผลเมื่อจบรอบ" และเกณฑ์ ≥ 4–5 คนถ้ากลุ่มเล็ก
2. ผู้ดูแลฐานข้อมูลที่ใช้เครื่องมือระดับลึก (transaction log) อาจเห็นลำดับการเขียนข้อมูลได้ — ระบบปกป้องในระดับแอปและตารางข้อมูล ไม่ใช่การเข้ารหัสแบบ cryptographic
3. โหมด **ลิงก์เปิด** กันโหวตซ้ำได้แค่ในหน้าต่างเบราว์เซอร์เดียว (ไม่มีทางกันซ้ำ 100% โดยไม่ระบุตัวตน) — ถ้าต้องการ 1 คน/รอบ จริง ๆ ให้ใช้ **โค้ดส่วนตัว**

## 📁 โครงสร้างโปรเจกต์

```
app.py                     หน้าเว็บทั้งหมด + routing ด้วย query params
moodwheel/feelings.py      รายการความรู้สึก/กลุ่ม/ระดับ (แก้ label ได้ แต่ห้ามเปลี่ยน code เดิม)
moodwheel/periods.py       รอบการโหวต (เวลาไทย Asia/Bangkok)
moodwheel/security.py      สุ่มรหัส/โค้ด/กุญแจ + hash
moodwheel/store.py         ฐานข้อมูล (SQLite ในเครื่อง / PostgreSQL บนคลาวด์)
moodwheel/logic.py         ด่านความเป็นส่วนตัว (เกณฑ์ขั้นต่ำ/ปิดผนึก) + สถิติ
moodwheel/viz.py           วงล้อ SVG 3D, เกจ, แถบสัดส่วน
moodwheel/ui.py            CSS และการ์ด UI
tests/                     ชุดทดสอบ (pytest + Streamlit AppTest)
.streamlit/config.toml     ธีม + ปิด usage stats
```

## 🚀 ขึ้น GitHub + Streamlit Community Cloud (ฟรี) เพื่อได้ลิงก์ให้คนอื่นใช้

> ⚠️ ดิสก์ของ Streamlit Cloud **ถูกล้างทุกครั้งที่แอปรีสตาร์ต** — ต้องใช้ฐานข้อมูล PostgreSQL ภายนอก (ฟรี) ไม่อย่างนั้นผลโหวตจะหาย
> แอปจะขึ้นคำเตือนสีเหลืองถ้ายังไม่ได้ตั้งค่า

### ขั้นที่ 1 — สร้างฐานข้อมูลฟรีที่ Neon (ประมาณ 3 นาที)
1. เข้า <https://neon.tech> → Sign up (ใช้บัญชี GitHub ได้)
2. **Create project** → ตั้งชื่อ เช่น `moodwheel` → Region เลือก **Asia Pacific (Singapore)** (ใกล้ไทยที่สุด)
3. ที่หน้า Dashboard กด **Connect** → คัดลอก **Connection string** หน้าตาประมาณ
   `postgresql://neondb_owner:xxxx@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
4. เก็บไว้ (เป็นความลับ ห้ามโพสต์ที่ไหน)

> ใช้ Supabase ก็ได้ — ให้ใช้ connection string แบบ **Session pooler** (ไม่ใช่ Direct connection)

### ขั้นที่ 2 — เอาโค้ดขึ้น GitHub
**แบบง่าย (ผ่านเว็บ ไม่ต้องใช้คำสั่ง)**
1. เข้า <https://github.com> → **New repository** → ตั้งชื่อ เช่น `moodwheel` → เลือก Public หรือ Private ก็ได้ → **Create repository**
2. กด **uploading an existing file** → แตกไฟล์ zip แล้วลาก *ทุกไฟล์และโฟลเดอร์* (รวม `.streamlit/` และ `moodwheel/`) ลงไป → **Commit changes**
   - ถ้าโฟลเดอร์ `.streamlit` ไม่ขึ้น (บางเครื่องซ่อนไฟล์ที่ขึ้นต้นด้วยจุด) ให้กด **Add file → Create new file** แล้วพิมพ์ชื่อ `.streamlit/config.toml` และวางเนื้อหาจากไฟล์นั้น

**แบบใช้ git**
```bash
cd moodwheel-app
git init && git add . && git commit -m "Mood wheel app"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/moodwheel.git
git push -u origin main
```
> ห้าม commit ไฟล์ `.streamlit/secrets.toml` (มีใน `.gitignore` แล้ว)

### ขั้นที่ 3 — Deploy บน Streamlit Community Cloud
1. เข้า <https://share.streamlit.io> → Sign in ด้วย GitHub → อนุญาตให้เข้าถึง repo
2. กด **Create app** → **Deploy a public app from GitHub**
3. เลือก Repository = `moodwheel`, Branch = `main`, Main file path = `app.py`
4. **App URL** ตั้งชื่อสวย ๆ เช่น `noina-mood` → จะได้ `https://noina-mood.streamlit.app`
5. กด **Advanced settings**
   - Python version: **3.12**
   - Secrets: วางข้อความนี้ (แก้เป็นของจริง)
     ```toml
     DATABASE_URL = "postgresql://…ที่คัดลอกจาก Neon…"
     APP_URL = "https://noina-mood.streamlit.app"
     ```
6. กด **Deploy** → รอ 1–3 นาที

### ขั้นที่ 4 — ใช้งาน
1. เปิดลิงก์แอป → แท็บ **✨ สร้างบอร์ดของฉัน** → ใส่ชื่อ (เช่น น้อยหน่า) → สร้าง
2. **ดาวน์โหลด/บันทึกกุญแจเจ้าของ** (แสดงครั้งเดียว กู้คืนไม่ได้) และ **ลิงก์เชิญส่วนตัว**
3. ส่งลิงก์เชิญให้ **1 คน : 1 ลิงก์** (LINE, IG DM ฯลฯ) — หรือถ้าเลือกโหมดลิงก์เปิด ก็แชร์ลิงก์เดียวได้เลย
4. ดูผลด้วย **ลิงก์ส่วนตัวของเจ้าของ** หรือแท็บ **📊 ดูผลบอร์ดของฉัน**
5. คนอื่นอยากมีบอร์ดของตัวเอง → เปิดแอปแล้วกดสร้างบอร์ดได้เลย

### หมายเหตุการดูแล
- Streamlit Cloud จะให้แอป "หลับ" เมื่อไม่มีคนเข้านาน ๆ — คนแรกที่เข้าอาจต้องกดปุ่มปลุกและรอสักครู่ ข้อมูลไม่หายเพราะอยู่ใน Neon
- แก้โค้ดบน GitHub → Streamlit Cloud deploy ใหม่ให้อัตโนมัติ
- ในหน้า App analytics ของ Streamlit Cloud ผู้ชมแอปสาธารณะที่อยู่นอก workspace จะแสดงเป็นนามแฝง แต่ยังเห็นจำนวน/เวลาเข้าชม — นี่เป็นอีกเหตุผลที่ค่าเริ่มต้นคือ "เปิดผลเมื่อจบรอบ"
